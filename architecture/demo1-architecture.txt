# Cedar Policy Example

permit(
    principal,
    action in [
        Action::"customers-mcp___list_customers",
        Action::"customers-mcp___get_customer_by_id",
        Action::"orders-mcp___list_orders"
    ],
    resource == Gateway::"<GATEWAY_ARN>"
)
when {
    principal.hasTag("group") &&
    principal.getTag("group") == "ReadOnly"
};

# Request Flow

1. GitHub Copilot calls MCP tool (e.g., list_customers)
2. VS Code MCP client → Local MCP Proxy (stdio)
3. MCP Proxy signs request with IAM user credentials (SigV4)
4. HTTPS POST to AgentCore Gateway
5. Gateway validates signature, reads IAM tags
6. Cedar evaluates: Does alice@company.com (ReadOnly) have permission?
7. If permit: Route to Customers Lambda MCP
8. If deny: Return 403 Forbidden
9. Lambda executes tool, returns result
10. Response flows back: Lambda → Gateway → Proxy → Copilot → VS Code

# Key Components

- AgentCore Gateway: AWS-managed service (preview)
- Cedar Policies: Tag-based RBAC rules
- Lambda MCPs: Tool implementations (Python 3.11)
- MCP Proxy: Local bridge (stdio → HTTPS)
- VS Code: Developer interface

# Security Model

- Authentication: IAM user credentials (SigV4)
- Authorization: Cedar policies + IAM tags
- Audit: CloudWatch logs (every tool call logged with IAM principal)
